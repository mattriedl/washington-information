Washington Area Codes

Which area code covers which part of Washington: 206, 253, 360, 425, 509 and 564.

Home › Washington Area Codes

Washington has six area codes. Four of them split up western Washington: 206 covers Seattle and a few close-in suburbs, 253 covers Tacoma and the south end of the Puget Sound metro, 425 covers the Eastside and southern Snohomish County, and 360 covers the rest of western Washington. 564 is an overlay that adds new numbers in the 360 area (since 2017) and in Seattle’s 206 area (since 2025). East of the Cascades, the whole region uses 509. Ten-digit dialing (area code plus number) is required for local calls throughout Washington.

Area Code 206

Major cities: Seattle, Shoreline, Burien, Mercer Island, Lake Forest Park, Tukwila, SeaTac, Normandy Park.

Area Code 253

Major cities: Tacoma, Kent, Federal Way, Auburn, Lakewood, Puyallup, University Place, Bonney Lake, Gig Harbor, Sumner, Fife, Milton.

Area Code 425

Major cities: Bellevue, Everett, Renton, Kirkland, Redmond, Sammamish, Lynnwood, Bothell, Edmonds, Issaquah, Mukilteo, Mill Creek, Woodinville.

Area Codes 360 and 564

Counties: Clallam, Clark, Cowlitz, Grays Harbor, Island, Jefferson, Kitsap, Lewis, Mason, Pacific, San Juan, Skagit, Skamania, Thurston, Wahkiakum, Whatcom, plus northern Snohomish County and parts of Pierce County.

Major cities: Vancouver, Olympia, Bellingham, Marysville, Lacey, Bremerton, Longview, Mount Vernon, Port Angeles, Aberdeen, Oak Harbor, Camas, Centralia.

Area Code 509

Counties: Adams, Asotin, Benton, Chelan, Columbia, Douglas, Ferry, Franklin, Garfield, Grant, Kittitas, Klickitat, Lincoln, Okanogan, Pend Oreille, Spokane, Stevens, Walla Walla, Whitman, Yakima.

Major cities: Spokane, Spokane Valley, Yakima, Kennewick, Pasco, Richland, Wenatchee, Walla Walla, Pullman, Moses Lake, Ellensburg, Clarkston.

Area code boundaries follow telephone exchanges, not county lines, so communities near the edges can be exceptions. Cell phone numbers keep the area code where they were issued.

Frequently Asked Questions

What are the area codes in Washington?

Washington has six area codes: 206 (Seattle), 253 (Tacoma and south King County), 425 (the Eastside and southern Snohomish County), 360 and its overlay 564 (the rest of western Washington), and 509 (eastern Washington).

What area code is Seattle, Washington?

Seattle uses area code 206. Since 2025, some new Seattle numbers are issued in the 564 overlay.

What area code is Spokane, Washington?

Spokane uses area code 509, like the rest of eastern Washington.

What area code is Tacoma, Washington?

Tacoma uses area code 253.

What area code is Bellevue, Washington?

Bellevue and most of the Eastside use area code 425.

What area code is Vancouver, Washington?

Vancouver uses area code 360, with new numbers also issued in the 564 overlay.

Do I need to dial the area code for local calls in Washington?

Yes. Ten-digit dialing is required for local calls throughout Washington, because of the 564 overlay in western Washington and the 988 crisis line change in the 509 area.
