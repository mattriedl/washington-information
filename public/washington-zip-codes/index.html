Washington ZIP Codes

All 715 Washington ZIP codes, searchable by ZIP code, city or county.

Home › Washington ZIP Codes

Washington has 715 active ZIP codes, and every one of them begins with 98 or 99. 522 are standard delivery ZIP codes, and the rest are PO box or single-organization ZIP codes. The first three digits point to a region: 980–981 cover Seattle and King County; 982 covers Everett, Snohomish County and the North Sound; 983–984 cover Tacoma, Pierce County and the Kitsap Peninsula; 985 covers Olympia and the coast; 986 covers Vancouver and Clark County; 988 covers Wenatchee and north-central Washington; 989 covers Yakima; 990–992 cover Spokane and the rest of Eastern Washington; 993 covers the Tri-Cities; and 994 covers Clarkston. Frequently Asked Questions

How many ZIP codes are in Washington?

Washington has 715 active ZIP codes: 522 standard delivery ZIP codes plus PO box and single-organization ZIP codes.

What do Washington ZIP codes start with?

Every Washington ZIP code starts with 98 or 99, running from 98001 (Auburn) to 99403 (Clarkston).

What is the ZIP code for Seattle, Washington?

Seattle has dozens of ZIP codes, all starting with 981, including 98101, 98102, 98103, 98104, 98105, 98106, 98107, 98108. Downtown Seattle is mainly 98101, 98104 and 98121.

What is the ZIP code for Spokane, Washington?

Spokane ZIP codes include 99201, 99202, 99203, 99204, 99205, 99206, 99207, 99208.

What is the ZIP code for Tacoma, Washington?

Tacoma ZIP codes include 98402, 98403, 98404, 98405, 98406, 98407, 98408, 98409.

What is the ZIP code for Olympia, Washington?

Olympia ZIP codes include 98501, 98502, 98506, 98512, 98513, 98516.

Does a ZIP code tell me which city I live in?

Not always. ZIP codes are drawn for mail delivery, so many homes outside city limits use a nearby city’s name and ZIP code. Check your county’s property records to confirm which city, if any, you are in.
